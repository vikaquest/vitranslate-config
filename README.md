# ViTranslate — конфигурация поддержки

Публичные данные окна «Поддержать проект». Не храните здесь пароли, токены или другие секреты.

JSON: https://vikaquest.github.io/vitranslate-config/donation.json

## Как менять реквизиты

1. Откройте donation.json и нажмите кнопку редактирования.
2. Измените message и paymentUrl. Сохраните изменения через Commit changes.
3. Для нового QR загрузите PNG, укажите его адрес в qrImageUrl и SHA-256 файла в qrSha256. В Windows хеш показывает PowerShell: `Get-FileHash .\support-qr.png -Algorithm SHA256`.
4. Чтобы отключить реквизиты поддержки, установите enabled в false. Остальные поля можно оставить.

После публикации GitHub Pages изменения доступны приложению без нового релиза. Реквизиты и ссылки загружаются только при каждом открытии окна поддержки по нажатию на сердечко. Во время запроса показана загрузка; при недоступности GitHub используется GitFlic. Без интернета используются последние корректные данные; перевод работает локально.

schemaVersion пока всегда 1. QR должен быть PNG на этом же сайте. QR и ссылка должны вести на одинаковые реквизиты: приложение проверяет целостность изображения, но не соответствие его содержимого ссылке.

## Соцсети и почта

В объекте `socialLinks` меняйте `telegram`, `instagram`, `github`, `gmail` и `yandex`. Для страниц указывайте HTTPS-ссылку, для почты — `mailto:адрес@домен`. Пустая строка скрывает соответствующую иконку. Если `socialLinks` отсутствует, ряд иконок скрыт; прежний JSON продолжает поддерживаться. Адреса сохраняются в локальном кэше вместе с реквизитами. При изменении данных обновляйте JSON также в резервном проекте GitFlic.
